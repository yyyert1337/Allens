# Allens

Удобный и быстрый менеджер установки приложений для Windows с современным интерфейсом и поддержкой пакетной установки.

---

## Возможности

- **Пакетная установка**: одновременный выбор нескольких необходимых программ и их автоматическая тихая установка в фоновом режиме.
- **Удобная каталогизация**: разделение программного обеспечения по категориям (системные утилиты, разработка, мультимедиа, браузеры и др.).
- **Очередь загрузок**: отслеживание прогресса скачивания каждого элемента с контролем скорости и проверкой целостности файлов.
- **Обнаружение установленного ПО**: автоматическое сканирование системы для выявления уже установленных приложений.
- **Встроенная система обновлений**: автоматическая проверка свежих версий самой программы.
- **Эстетичный темный интерфейс**: легковесное приложение на базе WPF (.NET 8) с плавной прокруткой и современным дизайном.

---

## Установка и запуск

Готовая сборка доступна на странице [Releases](https://github.com/yyyert1337/Allens/releases/latest).

1. Скачайте исполняемый файл `Allens.exe`.
2. Запустите программу от имени администратора для корректной установки приложений.

---

## Сборка проекта

### Требования
- .NET 8.0 SDK или новее
- Windows 10 / 11 (x64)

### Команда публикации
```bash
dotnet publish -c Release -r win-x64 --self-contained true
```
